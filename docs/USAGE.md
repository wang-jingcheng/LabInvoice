# 使用指南

## 成员提交票据

1. 登录后选择管理员派发的收集任务。首次使用可注册账号，由管理员将账号加入任务。
2. 选择报销项，分别添加主发票和附件。发票、行程单、支付凭证和材料明细各自放在对应位置，可分批追加并填写备注。
3. 保存至草稿箱，预览原票并核对每张金额。标为「—」的金额需要手动填写。
4. 正式提交。需要补充或修正时，请联系管理员退回。如果已归入经费项目，管理员需先移回待归类。
5. 管理员代为登记的无电子发票报销项和金额显示在对应任务内。

## 管理员整理报销

1. 添加成员并发布「日常业务报销」或「国内差旅费」收集任务。在任务详情查看各成员的提交情况。
2. 在「票据整理」创建经费项目，填写名称和编号，按成员、任务、报销项或关键词查找发票。
3. 勾选已提交的票据并批量归类，也可拖到对应项目或报销项。打开票据详情可预览原件、修改报销项及校准金额。
4. 将劳务费或暂时只有纸质发票的报销作为「无电子发票报销项」登记。该项会计入任务和项目汇总，也会作为独立明细导出。
5. 核对按报销项、按成员汇总的金额，下载原件 ZIP 或选择文件合并 PDF。

**结束收集**会锁定成员的上传、修改和提交，管理员仍可归类。**结项**会把任务从当前整理列表移出。关联任务全部结项的经费项目进入「已归档项目」，可继续查看汇总或导出。想恢复填写时，先撤销结项，再重新开放收集。

在「成员管理」中可以修改姓名和登录账号、重设密码或删除账户。删除账户会关闭登录权限，并保留其历史票据及报销记录。

## 文件与导出

| 操作 | 支持 |
| --- | --- |
| 上传主发票 | PDF、PNG、JPEG/JFIF、WebP、BMP、GIF、TIFF |
| 上传附件 | 主发票所支持的格式，以及 Word、Excel、ZIP、RAR、7Z |
| 识别金额 | 尝试提取 PDF 文本层中的金额。图片和扫描件需人工填写 |
| 项目 ZIP | 原始票据与附件、报销项和人员 CSV 小计、无电子发票明细、文件清单 |
| 合并 PDF | 默认选中主发票。可选入 PDF 和常见图片附件 |
| 任务原始资料 ZIP | 指定任务的原始票据、附件及元数据，包括草稿 |

单次上传请求上限为 128 MB，文件可分批追加。使用反向代理时，实际请求上限也受代理配置影响。

站内 `/help` 为团队操作说明。管理员可在「说明设置」维护适用于本单位的报销项、必备附件和其他细则。
